# Hoho Personal Portfolio

Mở `index.html` bằng trình duyệt để chạy.

## Cấu trúc
- `index.html`: giao diện
- `css/style.css`: toàn bộ CSS
- `js/script.js`: chuyển sáng/tối, menu active, nút về đầu trang
- `image/profile.png`: ảnh đại diện lấy từ ảnh mẫu người dùng cung cấp
- `image/sky-light.svg`: nền mây sáng
- `image/sky-dark.svg`: nền mây tối + trăng
- `image/footer-clouds.svg`: mây trang trí chân trang
- `image/icons.svg`: bộ icon SVG cục bộ

## Thay ảnh cá nhân
Chỉ cần thay `image/profile.png` bằng ảnh mới, giữ nguyên tên file là được.

## Thay thông tin
Các nội dung như ngày sinh, trường, email, SĐT, địa chỉ... nằm trực tiếp trong `index.html`.
